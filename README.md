# Auviora Showcase

Build a premium cinematic website for:

SLN AUVIORA MEDIA PRIVATE LIMITED

This is a professional outdoor advertising and billboard media company.

The website must NOT look like a normal corporate website, template, SaaS website, restaurant website, or generic digital marketing agency.

It should feel like a luxury international advertising/media brand.

REFERENCE STYLE:

Use the visual direction of:
https://luxury.aitiinterieurs.com

Do NOT copy the website, branding, text, images, or proprietary design.
Use it only as inspiration for:
- cinematic storytelling
- immersive full-screen media
- minimal luxury typography
- large visual sections
- smooth transitions
- premium spacing
- sophisticated animation
- scroll-based storytelling
- editorial composition

BRAND:

Company:
SLN AUVIORA MEDIA PRIVATE LIMITED

Use the uploaded SLN logo as the exact brand logo.

Do not redesign the logo.

Primary visual identity:
- very dark navy / black background
- premium warm gold accents derived from the logo
- white typography
- subtle gray secondary text
- high contrast
- elegant and minimal

TYPOGRAPHY:

Use a premium combination of:
- elegant serif display font for major headlines
- modern clean sans-serif for body text and navigation

Suggested:
Playfair Display or Cormorant Garamond for large headlines.
Inter or Manrope for body/navigation.

Do not overuse fonts.

==================================================
ANIMATION SYSTEM
==================================================

This is extremely important.

Use smooth premium animation throughout the website.

Use Framer Motion or an equivalent high-quality animation system.

Animations should include:

1. Page-load reveal

2. Hero text stagger

3. Scroll-triggered text reveal

4. Image scale animation

5. Parallax image movement

6. Smooth section transitions

7. Horizontal billboard gallery movement

8. Hover image zoom

9. Button magnetic/subtle movement

10. Navigation transparency transition

11. Page transition

12. Scroll progress indicator

Animation timing should generally be between 400ms and 1200ms.

Use smooth easing.

Avoid excessive bouncing.

Avoid cartoon animations.

The website should feel cinematic rather than animated.
